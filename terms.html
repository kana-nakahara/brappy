Brappy（ブラッピー）宅配買取サービス利用規約

株式会社楽楽（以下「当社」といいます。）は、当社が運営するブランド品等の宅配買取サービス「Brappy（ブラッピー）」（以下「本サービス」といいます。）について、以下のとおり利用規約（以下「本規約」といいます。）を定めます。

お客様は、本規約の内容を確認し、同意したうえで本サービスを利用するものとします。

第1条（目的および適用範囲）

  1. 本規約は、本サービスの利用および当社とお客様との間で行われる商品の売買に関する権利義務関係を定めることを目的とします。
  2. 本規約は、本サービスを利用するすべてのお客様に適用されます。
  3. 当社がウェブサイト、LINE公式アカウントその他当社所定の方法であらかじめ提示し、お客様が確認できる状態に置いた利用条件および注意事項は、その内容と適用範囲が明確な限り、本規約と併せて適用されます。
  4. 個別の取引について当社とお客様が明示的に合意した条件が本規約と異なる場合は、当該個別条件を優先します。ただし、法令に反する条件は適用されません。

第2条（サービス内容）

  1. 本サービスは、お客様からブランドバッグ、財布、時計、アクセサリー、衣類その他当社が取り扱う商品（以下「商品」といいます。）を宅配方式によりお預かりし、査定および買取を行うサービスです。
  2. 当社は、商品のブランド、真贋、状態、付属品、市場相場、再販売の可能性その他の事情を総合的に考慮し、査定金額を決定します。
  3. 当社は、取扱対象商品、査定基準その他本サービスの内容を合理的な範囲で変更することがあります。
  4. 当社は、すべての商品について査定金額の提示または買取を保証するものではありません。

第3条（利用資格）

  1. 本サービスを利用できるお客様は、次の各号の条件をすべて満たす方とします。
    1. （1）満18歳以上であること。
    2. （2）日本国内に住所を有すること。
    3. （3）商品について適法な所有権および処分権限を有すること。
    4. （4）古物営業法その他関係法令に基づく本人確認に協力できること。
    5. （5）当社が指定する代金支払方法を利用できること。
    6. （6）反社会的勢力に該当せず、これらと社会的に非難されるべき関係を有しないこと。
  2. 当社は、18歳以上であっても高校生のお客様については、本サービスの利用をお断りします。
  3. 法人のお客様については、法人の存在、取引担当者の本人確認および取引権限を確認できることを利用条件とします。
  4. 法令上、代理人、後見人、保佐人その他の者の同意または権限確認が必要な場合、当社は必要な確認が完了するまで取引をお断りすることがあります。

第4条（申込みおよび宅配キット）

  1. お客様は、当社ウェブサイト、LINE公式アカウント、マイページその他当社が指定する方法により買取を申し込むものとします。
  2. お客様は、申込みに際して正確かつ最新の情報を申告するものとします。
  3. 当社は、必要に応じて宅配キットをお客様へ送付します。
  4. お客様は、商品の輸送中の破損、汚損等を防ぐため、適切に梱包するものとします。
  5. 商品の発送は、原則として当社が指定または手配する集荷方法によるものとします。
  6. 当社の事前承諾なく発送された商品については、受領または査定をお断りすることがあります。
  7. お客様が故意に空箱を発送し、架空の住所を申告し、その他不正または悪質な方法で本サービスを利用したことにより当社に損害が生じた場合、当社は、法令上認められる範囲で、合理的に発生した費用および損害の賠償を請求することがあります。

第5条（本人確認）

  1. 当社は、古物営業法その他関係法令に基づき、お客様の住所、氏名、職業、年齢その他法令上必要な事項を確認します。
  2. 非対面取引における本人確認は、古物営業法施行規則その他関係法令に定める方法で行います。具体的な確認書類、郵便物の送付方法、金融機関口座の確認、発送方法その他の手続は、適用する法定確認方法に応じて当社が案内します。LINEへのログインや本人確認書類の画像送信のみで法定の本人確認が完了するものではありません。
  3. お客様は、当社が指定する本人確認手続に協力し、必要な書類および情報を正確に提出するものとします。
  4. 本人確認が完了しない場合、当社は買取契約を成立させず、買取代金を支払いません。
  5. 提出された情報に虚偽、不備、矛盾または合理的な疑義が認められる場合、当社は追加資料の提出を求め、または取引をお断りすることがあります。
  6. 法人のお客様については、登記事項証明書、取引担当者の本人確認書類、委任状その他法令および当社の手続上必要な書類の提出を求めます。

第6条（買取対象外商品）

  1. 当社は、次の各号に該当する商品について、買取をお断りすることがあります。
    1. （1）偽造品、模倣品、盗品、遺失物その他違法性が疑われる商品
    2. （2）第三者の所有権、担保権その他の権利の対象となっている商品で、売却に必要な権限が確認できないもの
    3. （3）所有権または処分権限を確認できない商品
    4. （4）著しい破損、汚損、臭気、劣化等により再販売が困難な商品
    5. （5）ノーブランド品、ファストファッション商品その他当社の取扱基準に適合しない商品
    6. （6）法令により売買または取扱いが禁止もしくは制限されている商品
    7. （7）その他当社が客観的かつ合理的な理由により買取対象外と判断した商品

第7条（査定）

  1. 当社は、商品到着後、商品の状態、真贋、付属品、市場価格その他必要な事項を確認し、査定金額を提示します。
  2. LINE、写真、メールその他の方法による事前査定は概算であり、実物査定の結果と異なる場合があります。
  3. 査定金額には、当社が査定対象として確認した付属品等の価値を含むものとします。
  4. 査定金額の有効期間は、査定結果の通知時に当社が明示します。有効期間が経過した場合、当社は市場相場や商品の状態等を踏まえて再査定を行うことがあります。
  5. お客様は、提示された査定金額を確認し、買取の承諾またはキャンセルを選択できます。
  6. 当社は、査定に必要な範囲で商品や包装を開封し、内部、付属品、刻印その他の状態を確認することがあります。お客様は、包装紙、封印シールその他の梱包材が開封前の状態に復元できない場合があることを承諾するものとします。ただし、未開封であること自体が商品価値に影響すると合理的に見込まれる場合には、当社は開封の必要性を説明し、お客様の承諾を得たうえで開封します。当社は商品本体および査定対象の付属品を合理的な注意をもって取り扱い、当社の責めに帰すべき事由による損害については関係法令に従い対応します。
  7. 当社は、査定結果について可能な範囲で説明しますが、社内の査定基準、鑑定方法、価格算定方法、取引先情報その他営業上の秘密について、法令上開示義務がある場合を除き、開示する義務を負いません。

第8条（買取契約の成立および所有権の移転）

  1. 買取契約は、当社が実物査定金額を提示し、お客様がその金額での売却を承諾し、法令上必要な本人確認その他の手続が完了した時点で成立します。複数の商品については、当社とお客様が買取に合意した商品ごとに契約が成立します。
  2. 買取契約成立後は、法令上認められる場合または当社が承諾した場合を除き、お客様の都合によるキャンセル、商品の返還請求または買取金額の増額請求には応じられません。
  3. 商品の所有権は、当該商品の買取代金の支払完了時にお客様から当社へ移転します。契約成立から支払完了までの間、当社は商品を適切に保管し、滅失・毀損等については第15条および関係法令に従い対応します。
  4. お客様は、商品について適法な所有権および処分権限を有し、第三者の権利を侵害しておらず、当社に申告した重要事項が真実かつ正確であることを保証するものとします。

第9条（契約不適合品等への対応および契約解除）

  1. 買取契約成立後に、商品が偽造品、盗品、第三者の権利を侵害する商品、または申告された重要事項と異なる商品であること等が判明した場合、当社は、事実関係および契約内容に応じ、民法その他関係法令上の要件を満たす範囲で、履行の請求、代金減額、契約解除、損害賠償その他認められる措置を講じることがあります。疑義が生じたことのみを理由として当然に契約が解除されるものではありません。
  2. 契約が適法に解除された場合、当社およびお客様は、法令に従い受領済みの代金および商品の返還その他の原状回復を行います。商品が第三者に移転した場合、法令上返還できない場合、または商品を返還できない場合の処理は、具体的事情および関係法令に従います。
  3. 当社は、前各項に基づき契約の解除、買取代金の返還請求その他の措置を講じる場合、お客様に対し、その理由および必要な事項を通知するものとします。ただし、当社の査定基準、鑑定方法、調査資料、取引先情報その他当社または第三者の営業上の秘密に関する情報については、法令上開示義務がある場合を除き、開示する義務を負わないものとします。
  4. 当社は、商品の真贋、権利関係その他契約内容への適合性について合理的な疑義が生じた場合、必要な調査を行い、法令上認められる範囲で、未払代金の支払いを一時的に留保することがあります。
  5. 本条に基づく権利の行使期間、解除の要件その他の事項については、民法その他関係法令に従うものとします。

第10条（買取代金の支払い）

  1. 当社は、買取契約の成立および必要な本人確認の完了後、原則として3営業日以内に、お客様本人名義の金融機関口座へ買取代金を振り込みます。
  2. 法人のお客様の場合は、原則として当該法人名義の金融機関口座へ振り込みます。
  3. 当社は、第三者名義の金融機関口座への振込みには対応しません。
  4. 振込先情報の不備、金融機関の休業・システム障害、法令上必要な確認その他合理的な事情により入金が遅れる場合があります。この場合、当社は可能な範囲でお客様に通知します。
  5. 本規約における営業日とは、土曜日、日曜日、国民の祝日および当社が別途公表する休業日を除く日をいいます。

第11条（キャンセルおよび商品の返送）

  1. お客様は、買取契約成立前であれば、査定結果を確認したうえで買取をキャンセルすることができます。
  2. 買取契約成立前にお客様が買取をキャンセルした場合、または当社の買取基準に適合しない等の理由により買取が成立しなかった場合、当社は当社所定の方法で商品を返送します。複数商品のうち一部のみ買取が成立した場合、買取不成立の商品を返送します。
  3. 前項の返送に要する送料は、複数商品の一部返送の場合を含め、原則としてお客様の負担とし、着払いその他当社が指定する方法で返送するものとします。ただし、当社の責めに帰すべき事由により返送が必要となった場合は、この限りではありません。
  4. 商品の形状、大きさ、重量その他の事情により特別な配送方法を要する場合、その配送に必要な合理的な費用は、第3項に定める負担区分に従うものとします。
  5. 商品の返送先は、本人確認等により確認された住所その他法令上適切な宛先とします。

第12条（連絡不能商品および保管）

  1. 査定結果の通知後、お客様から回答がない場合、当社はLINE、メール、その他合理的な方法で再連絡を行います。連絡に用いる宛先は、お客様が申告した連絡先を原則とします。
  2. 当社が査定結果および回答を求める旨を通知し、その後の最終連絡から7日を経過してもお客様から回答がない場合、当社は返送予定をあらためて通知したうえで、当社所定の方法により商品を返送することがあります。返送料は原則としてお客様の負担とします。ただし、当社の責めに帰すべき事由による場合は、この限りではありません。7日の経過のみをもって売買契約の承諾または所有権放棄があったものとは扱いません。
  3. 返送先が不明である場合、返送商品が当社へ戻ってきた場合、その他返送ができない場合には、当社は関係法令に従い、保管、再通知その他適切な措置を講じるものとします。
  4. お客様の故意または過失により返送不能となり、追加の配送費用その他合理的な費用が発生した場合、当社は法令上認められる範囲で当該費用を請求することがあります。

第13条（商品に含まれる私物および付属品）

  1. お客様は、商品発送前に、バッグや衣類等の内部に現金、貴重品、私物その他買取対象外の物品が残されていないことを確認するものとします。
  2. 当社が買取対象外の物品を発見した場合、お客様に連絡のうえ、返送その他適切な方法により対応します。
  3. 前項の返送に要する費用は、当該物品の混入の事情等を考慮し、法令上認められる範囲でお客様に負担いただく場合があります。
  4. 商品に付属する箱、保存袋、保証書その他の付属品については、査定時に確認した範囲で商品と一体として取り扱う場合があります。
  5. 当社は、買取対象外の物品等について、法令上必要な管理および返還義務を負う場合を除き、買取対象商品として取り扱いません。

第14条（送料および査定料）

  1. 宅配キットの提供費用、当社指定の発送方法による送料および査定料は、原則として無料とします。
  2. 当社が指定しない方法による発送、特別な配送その他追加費用が発生する場合、その費用の負担については、本規約の定め、当該費用の発生原因および関係法令に従い取り扱うものとします。

第15条（配送中の事故および危険負担）

  1. 当社が指定した配送業者による輸送中に紛失、破損その他の事故が発生した場合、当社は配送業者への調査・補償請求に必要な協力を行い、事故原因、配送契約の内容、商品の価値および当社の責任の有無を確認して、関係法令に従い対応します。配送業者の補償限度額が当然に当社の損害賠償責任の上限となるものではありません。
  2. 当社が商品を受領した後、買取契約成立前または所有権移転前に、当社の責めに帰すべき事由により商品が滅失または毀損した場合、当社は関係法令に従い責任を負います。
  3. 商品の所有権移転の前後を問わず、商品の滅失・毀損に関する危険負担および損害賠償責任は、当事者の帰責事由、商品の引渡状況、契約内容その他の事情に応じ、民法その他関係法令に従い判断します。
  4. お客様は、配送事故の調査に必要な範囲で、商品に関する資料、写真その他合理的に必要な情報の提供に協力するものとします。

第16条（禁止事項）

  1. お客様は、本サービスの利用にあたり、次の各号に該当する行為を行ってはならないものとします。
    1. （1）虚偽の氏名、住所、本人確認情報その他の情報を申告する行為
    2. （2）偽造品、盗品、第三者の所有物その他不正な商品の売却を試みる行為
    3. （3）不正な換金、マネーロンダリングその他違法または不正な目的で本サービスを利用する行為
    4. （4）当社または第三者の権利、利益、信用もしくは名誉を侵害する行為
    5. （5）本サービスの運営を妨害する行為
    6. （6）法令または公序良俗に反する行為
    7. （7）その他当社が客観的かつ合理的な理由により不適切と判断する行為
  2. お客様は、当社の役員、従業員その他関係者に対し、暴言、脅迫、威嚇、執拗な要求、誹謗中傷その他社会通念上許容される範囲を超える行為（カスタマーハラスメント）を行ってはならないものとします。

第17条（取引の謝絶および利用停止）

  1. 当社は、お客様が次の各号のいずれかに該当する場合、合理的な理由に基づき、査定・買取の受付をお断りし、または本サービスの利用を停止することができるものとします。

    2. （2）本人確認その他法令上必要な確認に協力いただけない場合
    3. （3）申告内容に虚偽または重大な不備がある場合
    4. （4）不正な取引の疑いがある場合
    5. （5）当社または第三者に対してカスタマーハラスメントその他の不当な行為を行った場合
    6. （6）過去の取引における重大な規約違反等により、取引継続が適切でないと合理的に判断される場合
  2. 買取契約成立後に前項各号に該当する事実が判明した場合でも、当社が契約を解除できるのは、当該事実が契約の目的または信頼関係に重大な影響を及ぼし、民法その他関係法令上の解除要件を満たす場合に限ります。

  4. 本条に基づく措置により生じた損害については、当社の責任の有無を含め、関係法令に従い取り扱うものとします。

第18条（反社会的勢力の排除）
